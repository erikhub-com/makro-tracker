Abgleich mit zweitem Gerät

Deine selbst hinzugefügten Lebensmittel (auch Änderungen und Löschungen) werden über dein GitHub-Repo mit allen Geräten geteilt, auf denen derselbe Schlüssel eingetragen ist. Mahlzeiten, Gewicht, Rezepte und Ziele bleiben auf dem jeweiligen Gerät.

So bekommst du den Schlüssel

Auf github.com: Profilbild, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Bei Repository access „Only select repositories“ und makro-tracker wählen. Unter Permissions, Repository permissions, „Contents“ auf „Read and write“ stellen. Den Schlüssel danach auf beiden Geräten hier eintragen. Die Liste liegt in der Datei foods.json im öffentlich lesbaren Repo.
